# Снимки цен магазинов (раз в месяц, Москва)

## Методика
1. **Пятёрочка, база.** Раз в месяц снимаются цены всех ингредиентов (~130): `data/store_prices/p5_<YYYY-MM>.csv`.
2. **Остальные 7 сетей.** Раз в месяц снимается корзина из 25 сопоставимых продуктов (6–7 на категорию: овощи/фрукты, мясо/рыба, молочка/яйца, бакалея) во всех 8 сетях, включая Пятёрочку: `data/store_prices/basket_<YYYY-MM>.csv`.
3. Скрипт считает **индекс цен сети к Пятёрочке** по каждой категории: это среднее геометрическое отношений цен. Если в категории меньше 3 пар, берётся общий индекс сети.
   Цена продукта без собственной цены сети = цена Пятёрочки × индекс («оценка · индекс»).
4. Если у Пятёрочки нет цены на продукт, используется Росстат × коэффициент сети («оценка»).
5. Цены, которые реально видели на сайте (снимок, корзина, официальный API ВкусВилла и Ленты), помечены «цена магазина · дата».

**Правило цены:** всегда берётся **обычная (регулярная) цена**. Акции, скидки и цены по карте лояльности не берутся. Если показаны перечёркнутая старая цена и акционная, пишите старую.

## Шаги
1. `python3 tools/store_csv.py --template 2026-11` создаёт в `_template/` два файла: `p5_2026-11.csv` и `basket_2026-11.csv` (25 продуктов × 8 сетей). В колонке `query` уже стоит поисковый запрос для сайта.
2. В браузере, как обычный покупатель (Москва, без входа в аккаунт), ищите `query` и выбирайте обычный базовый товар. В корзине по возможности берите одинаковую фасовку во всех сетях.
3. Заполните колонки: `product_name`, `pack_size` (число), `unit` (г / кг / мл / л / шт), `regular_price` (₽, обычная цена), `url`, `date` (YYYY-MM-DD).
   Если товар продаётся на вес (цена за кг), пишите `pack_size=1`, `unit=кг`. Если товар не найден, оставьте цену пустой.
4. Положите файлы в `data/store_prices/` и запустите `python3 tools/store_csv.py` (сеть не нужна), затем закоммитьте `data/prices.json`.
   Если хотите заодно обновить API ВкусВилла и Ленты, запустите `python3 tools/update_prices.py --stores-only`.
5. Каждая цена пересчитывается на упаковку ингредиента из `js/data.js` и проверяется на правдоподобие (0,4…2,5 × оценки Росстата). Строки вне этого диапазона пропускаются с предупреждением. Из нескольких файлов берётся самый свежий месяц.
   Полный снимок сети важнее корзины, корзина важнее API. Цены из API ВкусВилла и Ленты тоже участвуют в расчёте индекса, если есть цена Пятёрочки.

Можно добавить и полный снимок любой другой сети: `<store>_<YYYY-MM>.csv` в том же формате, что и p5. Коды сетей: p5, magnit, perek, lenta, auchan, samokat, lavka, vkusvill.
